# Fuel Lockstep

Hong Kong's five petrol brands post the same pump price almost every day. This repo rebuilds every posted price since April 2020, runs collusion screens against costs, and compares Hong Kong with Los Angeles and Perth. Outputs: an interactive page (`index.html`), a write-up (`overview/`) and a LaTeX paper (`paper/`).

Read `docs/spec.md` before changing scope and `docs/decisions.md` before changing any data rule. Record new judgment calls in `docs/decisions.md`.

## Rules

- Numbers are never typed by hand. `scripts/export_numbers.py` writes `paper/numbers.tex` and `site/numbers.json`; `scripts/build_site.py` fills `site/index.template.html`, `site/overview.fragment.html` and `site/README.template.md`. Edit the templates, not `index.html` or `README.md`.
- `overview/index.html` is generated by `../../_ai-projects-tooling/overview-pages/build.py` from the fragment that `build_site.py` writes there. Run `fixdims.py` after.
- Do not mention any earlier essay on this topic. The project stands alone.
- Ledger base style (no family). `python3 ../../_ai-projects-tooling/ledger/designcheck.py .` must pass before a commit. No em dashes.
- `data/raw/` is gitignored. The FuelWatch monthly files are large; keep them outside My Drive with `FUEL_CACHE`.
